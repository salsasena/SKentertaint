# SK ENTERTAINMENT — Website

A clean, modern entertainment-company landing page in a light-blue brand style.

## Files
- `index.html` — main website
- `style.css` — design and responsive layout
- `script.js` — audition form interaction

## Run
Open `index.html` in a browser.

The trainee names and profiles are fictional. The Instagram button points to `@sallsna`.

## Deploy to GitHub Pages
1. Create a GitHub repository.
2. Upload the three website files.
3. Go to Settings → Pages.
4. Select the main branch and root folder.
5. Save and open the generated Pages URL.
